      تحديد العملية الذاكرة العدد

      العمليات المحمية لا يمكن انهاؤها حفاظاً على استقرار النظام.

      سلوك التعزيز التلقائي

      انهاء تطبيقات الخلفية تلقائياً محاولة إنهاء العمليات المدرجة عند بدء اللعب، باستثناء العمليات المحمية
      تفريغ ذاكرة العمليات الخلفية طلب تقليص الذاكرة المقيمة للعمليات؛ قد يعيد Windows تحميلها عند الحاجة
      حظر الاشعارات اثناء اللعب تعديل إعدادات إشعارات Windows مؤقتاً ثم محاولة استعادة القيم السابقة
      تعطيل مسجل الالعاب تعديل إعدادات تسجيل الألعاب في Windows ثم محاولة استعادة القيم السابقة
      تفعيل خطة الاداء العالي التبديل إلى خطة أداء عالية متاحة ثم محاولة استعادة الخطة السابقة
      رفع اولوية اللعبة طلب تعيين عملية اللعبة على أولوية عالية؛ قد يرفض Windows هذا التغيير
      انشاء خطة الاداء القصوى اضافة خطة الطاقة القصوى الى النظام ويتطلب ذلك صلاحيات المسؤول
      التشغيل مع بدء تشغيل ويندوز تشغيل LagZero تلقائياً عند تسجيل الدخول إلى Windows
